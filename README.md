# style-guide-archives-editorial

Editorial and publishing style manuals, house style guides, typography handbooks and printers' manuals.

This repository is one part of the [Style Guide Archives](https://github.com/WPTK/style-guide-archives), a public collection of style guides from around the world.

- **216 guides, 1.87 GB**
- Layout: `<category>/<organisation>/<year>-<title>.pdf`
- [INDEX.md](INDEX.md) lists every file with its year, size and the page it came from
- The full catalog, with leads for guides not archived yet, is [CATALOG.md](https://github.com/WPTK/style-guide-archives/blob/master/CATALOG.md)

## Cloning

```
git clone https://github.com/WPTK/style-guide-archives-editorial.git
```
